# 湍流闭合的可实现应力张量投影

地形基与湍流动能的应力闭合约定。 仓库记录均为本地合成资料，不依赖外部数据服务。

## 数据约定

base 是地形局部基的对称应力。frame 的列是三个单位局地基在全局坐标中的表示。hard 左右界对应同一全局单位方向的二次型，等界表示固定。soft 给方向目标及非负惩罚权。平方 Frobenius 偏差加各软方向的加权平方偏差为最近投影目标。

应力迹与半正定适用同一张量，半正定允许零特征值。交付定向动量通量为全局应力作用于 query 单位向量。种子各自配对全局应力矩阵和定向通量。只对原始对称张量的独立自由度和软目标回传。

accuracy 同时适用于特征值最小值、迹和硬方向值的绝对容差。radius 是上游请求的局地张量与软目标联合扰动半径，求导适用域应以公开资料作检验。

## 读取与核对

在 Python 3.11 环境执行 `python -m pip install -r requirements.txt` 安装数值依赖。
`python -m unittest discover -s tests -v` 读取 `data/exchange.json` 并核对资料结构与关键输入关系。
